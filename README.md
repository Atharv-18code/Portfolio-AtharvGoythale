# Atharv Vidyadhar Goythale - Portfolio

A modern, responsive portfolio website built with React, TypeScript, Vite, Tailwind CSS, and Framer Motion.

## Features

- 🎨 Dark futuristic color scheme
- 📱 Fully responsive design
- ✨ Smooth animations with Framer Motion
- 📧 Contact form with Formspree integration
- 📈 Glassmorphism UI effects
- 📱 Mobile-first approach

## Tech Stack

- React 18
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Build for Production

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```

## Deployment

### Deploy to Vercel (Recommended)

1. Connect your GitHub repo to Vercel
2. Vercel will automatically deploy your site on every push

### Deploy to Netlify

1. Connect your GitHub repo to Netlify
2. Netlify will automatically deploy your site on every push

### Deploy to GitHub Pages

1. Build the project with `npm run build`
2. Deploy the `dist` folder

## Contact Form

The contact form is integrated with Formspree. Sign up at https://formspree.io/ to get your form endpoint and update the `FORM_ENDPOINT` in `src/components/Contact.tsx`.
